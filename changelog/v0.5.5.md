# v0.5.5 更新日志

**发布日期**: 2026-06-28

## 概述

v0.5.5 是一个功能增强版本，新增了图嵌入模块（Node2Vec、DeepWalk、Struc2Vec、Inf2Vec）、基于图注意力网络和结构洞的启发式算法（GATSH）、基于嵌入的影响力最大化算法（IMInfector）、全局随机种子控制功能，重构了启发式算法模块的组织结构，统一了所有文档注释风格为 Google 风格，并新增了双向图转换工具函数。

## 🚀 新增算法

### 图嵌入模块

新增独立的图嵌入模块 `pynetim.embedding`，提供图节点嵌入算法。

**模块结构**:

```
embedding/
├── __init__.py      # 模块导出
├── base.py          # BaseEmbedding 基类
├── node2vec.py      # Node2Vec 算法
├── deepwalk.py      # DeepWalk 算法
├── struc2vec.py     # Struc2Vec 算法
└── inf2vec.py       # Inf2Vec 算法
```

**支持的算法**:

| 算法        | 特点                       | 游走方式      |
| --------- | ------------------------ | --------- |
| Node2Vec  | 有偏随机游走，p/q 参数控制 BFS/DFS  | 别名采样加速    |
| DeepWalk  | 均匀随机游走，Node2Vec 的特例      | 简单随机选择    |
| Struc2Vec | 结构等价性随机游走，捕获节点结构角色       | 多层图 + DTW |
| Inf2Vec   | 社交影响嵌入，Source/Target 双嵌入 | RWR + 级联  |

**训练后端**:

- `gensim`: 使用 gensim 的 Word2Vec（推荐）
- `pytorch`: 纯 PyTorch 实现（已有依赖）
- `auto`: 自动选择（默认）

**参考文献**:

- Grover, A., & Leskovec, J. (2016). node2vec: Scalable Feature Learning for Networks. KDD.
- Perozzi, B., Al-Rfou, R., & Skiena, S. (2014). DeepWalk: Online Learning of Social Representations. KDD.
- Ribeiro, L. F. R., Saverese, P. H. P., & Figueiredo, D. R. (2017). struc2vec: Learning Node Representations from Structural Identity. KDD.
- Bourigault, S., Lagnier, C., Lamprier, S., Denoyer, L., & Gallinari, P. (2016). Learning Social Network Embeddings for Predicting Information Diffusion. WSDM.

**使用示例**:

```python
from pynetim import IMGraph
from pynetim.embedding import Node2Vec, DeepWalk

graph = IMGraph(edges, weights=0.3)

# Node2Vec (DFS-like)
model = Node2Vec(graph, dimensions=64, p=1, q=0.5)
model.train()
embeddings = model.get_all_embeddings()

# DeepWalk
model = DeepWalk(graph, dimensions=64)
model.train()
embeddings = model.get_all_embeddings()

# 查找相似节点
similar = model.most_similar(0, topn=5)
```

### GATSH 算法

新增基于图注意力网络和结构洞的影响力最大化算法。

**算法特点**:

- 结合图注意力网络(GAT)和结构洞(Structural Holes)理论
- 使用 GAT 学习节点间的注意力权重
- 基于注意力权重计算节点的约束系数
- 约束系数越小，节点越容易成为结构洞节点，影响力越大

**参考文献**:

- Social Network Influence Maximization Based on Graph Attention Mechanisms. ICETIS 2024.

**使用示例**:

```python
from pynetim import IMGraph
from pynetim.algorithms import GATSHAlgorithm

graph = IMGraph(edges, weights=0.3)
algo = GATSHAlgorithm(graph, hidden_dim=64, heads=8)
seeds = algo.run(k=10)
```

### IMInfector 算法

新增基于嵌入的影响力最大化算法 IMInfector，利用 Inf2Vec 学习的 Source/Target 嵌入计算影响概率矩阵，通过贪心策略选择种子节点。

**算法特点**:

- 基于影响概率矩阵 D = softmax(S · T^T) 进行种子选择
- 每个候选种子的预算由其 Source 嵌入的 L2 范数决定
- 使用类似 CELF 的贪心策略，支持 lazy evaluation 优化
- 与 Inf2Vec 嵌入模块配合使用，职责分离

**架构设计**:

- `embedding.Inf2Vec`: 负责训练 Source/Target 嵌入
- `algorithms.deep_learning.IMInfectorAlgorithm`: 负责基于嵌入的种子选择（归属深度学习子模块）

**参考文献**:

- Panagopoulos, G., Malliaros, F., & Vazirgiannis, M. (2020). Multi-task Learning for Influence Estimation and Maximization. IEEE TKDE.
- Panagopoulos, G., Malliaros, F. D., & Vazirgiannis, M. (2020). Influence Maximization Using Influence and Susceptibility Embeddings. ICWSM.

**使用示例**:

```python
from pynetim import IMGraph
from pynetim.embedding import Inf2Vec
from pynetim.algorithms import IMInfectorAlgorithm

graph = IMGraph(edges, weights=0.3)
cascades = [[0, 1, 3], [2, 4, 5, 1]]

# 1. 训练嵌入
inf2vec = Inf2Vec(graph, cascades=cascades, dimensions=64)
inf2vec.train()

# 2. 基于嵌入选择种子
algo = IMInfectorAlgorithm(graph, inf2vec_model=inf2vec)
seeds = algo.run(k=5)

# 也可以直接提供嵌入矩阵
algo = IMInfectorAlgorithm(graph, source_embeddings=S, target_embeddings=T)
seeds = algo.run(k=5)
```

## 🎯 新增功能

### 全局随机种子控制（C++ 模块）

新增 `pynetim.random` 子模块，提供 C++ 模块（扩散模型、RIS 算法等）的全局随机种子控制功能。
C++ 模块通过 pybind11 回调 Python 端获取 `_global_seed`，确保跨共享库共享同一份种子状态。

Python 层面（Python random、NumPy、PyTorch 等）的随机种子由用户自行管理，本模块不做干预。

**模块结构**:

```
pynetim/
├── random/
│   └── __init__.py      # 种子存储 + Python 封装
└── cpp/
    └── bindings/        # 通过 py::module_::import() 回调 Python
```

**支持的 C++ 模块**:

| 模块           | 支持全局种子 |
| ------------ | ------ |
| IC/LT/SI/SIR 模型 | ✅      |
| IMM/TIM/TIM+ 算法 | ✅      |
| OPIM/OPIM-C 算法  | ✅      |

**API**:

| 函数 | 说明 |
| --- | --- |
| `seed(seed_value)` | 设置 C++ 模块的全局随机种子 |
| `clear_seed()` | 清除全局随机种子 |
| `get_random_seed()` | 获取当前全局随机种子 |
| `has_seed()` | 检查是否已设置全局随机种子 |

**种子优先级**:

当调用扩散模型或算法时，种子使用优先级为：

1. **局部参数** `random_seed=123`：使用指定的局部种子
2. **全局种子** `pynetim.random.seed(42)`：使用全局种子
3. **真随机**：以上都未设置时使用真随机

### 双向图转换工具函数

新增双向图转换工具函数，支持从其他图库格式转换为 IMGraph，与现有的 `to_*` 函数形成完整的双向转换支持。

**新增函数**:

| 函数                  | 说明                                  |
| ------------------- | ----------------------------------- |
| `from_networkx`     | 从 networkx.Graph/DiGraph 创建 IMGraph |
| `from_igraph`       | 从 igraph.Graph 创建 IMGraph           |
| `from_scipy_sparse` | 从 scipy 稀疏矩阵创建 IMGraph              |
| `from_pyg`          | 从 PyTorch Geometric Data 创建 IMGraph |

**完整转换支持**:

| 源格式               | → IMGraph             | IMGraph →           |
| ----------------- | --------------------- | ------------------- |
| networkx          | `from_networkx()`     | `to_networkx()`     |
| igraph            | `from_igraph()`       | `to_igraph()`       |
| scipy.sparse      | `from_scipy_sparse()` | `to_scipy_sparse()` |
| PyTorch Geometric | `from_pyg()`          | `to_pyg()`          |

**使用示例**:

```python
import networkx as nx
import igraph as ig
from pynetim import from_networkx, from_igraph, to_networkx, to_igraph

# 从 networkx 创建 IMGraph
nx_g = nx.DiGraph()
nx_g.add_edge(0, 1, weight=0.5)
nx_g.add_edge(1, 2, weight=0.8)
g = from_networkx(nx_g)
print(f"节点数: {g.num_nodes}")  # 3

# 从 igraph 创建 IMGraph
ig_g = ig.Graph(n=3, edges=[(0, 1), (1, 2)], directed=True)
ig_g.es['weight'] = [0.5, 0.8]
g = from_igraph(ig_g)
print(f"节点数: {g.num_nodes}")  # 3

# IMGraph 转换为其他格式
nx_g = to_networkx(g)
ig_g = to_igraph(g)
```

## ✨ 改进

### 代码优化

- 移除 `generators.py` 中重复的 import 语句
- 移除 `graph_utils.py` 中函数内部的重复 import 语句
- 图生成函数（`generate_er_graph`, `generate_ba_graph`, `generate_ws_graph`）返回时设置 `renumber=False`，保持节点编号连续
- 修复 `utils/__init__.py` 中 `generate_*` 函数的导入路径问题

### 随机种子控制精简

`pynetim.random` 模块仅控制 C++ 模块（扩散模型、RIS 算法等）的随机种子，
不再干预 Python random、NumPy、PyTorch 的随机状态。Python 层面的随机种子由用户自行管理。

- `seed()`: 移除了对 `random.seed()`、`np.random.seed()`、`torch.manual_seed()` 的调用
- `clear_seed()`: 移除了对上述模块的清理调用
- 文档注释更新，明确本模块职责范围

### ToupleGDD 设备一致性修复

修复 ToupleGDD 算法中 `_init_state()` 方法未将状态张量放置在正确设备上的问题。
两个 ToupleGDD 实现的 `_init_state()` 现在均传入 `device=self.device`，避免设备不一致错误。

### ToupleGDD / S2V-DQN 推理加速

优化 ToupleGDD 和 S2V-DQN 算法在迭代选择种子节点时的推理性能。

每次调用 `_compute_q_values()` 时，`_setup_graph_input()` 会完全重建图结构数据（`edge_index`、`edge_weight`/`edge_attr` 等），但这些结构在推理过程中从不变化，只有 `state` 向量随迭代更新。将不变部分在 `_prepare_inference()` 中一次性缓存：

| 缓存字段 | 说明 |
| --- | --- |
| `_cached_edge_index` | 边索引张量，两算法共用 |
| `_cached_edge_weight` | 边权重张量（ToupleGDD） |
| `_cached_x` | 节点特征基座，全 1 张量（S2V-DQN） |
| `_cached_edge_attr` | 边属性基座，预填充边权重列（S2V-DQN） |

`_setup_graph_input()` 仅 clone 缓存基座 + 更新依赖 `state` 的部分。迭代选择时图结构构建从 `O(k * (V + E))` 降至 `O(k * E)`。

### 种子集保留选择顺序

种子集 `self.seeds` 从 `Set[int]` 改为 `List[int]`，按选择顺序存储种子节点。所有继承自 `BaseAlgorithm` 的算法均已适配。

- `run()` 返回类型保持 `Set[int]`（向后兼容）
- `get_seeds()` 保持返回 `Set[int]`（向后兼容）
- 新增 `get_seeds_ordered() -> List[int]`：返回按选择顺序排列的种子列表

**受影响的模块**：`heuristic`（10 个算法）、`simulation`（Greedy/CELF/CELF++）、`deep_learning`（IMInfector）、`reinforcement_learning`（BaseDRL/CoreQ/TCQ）、`population`（RLSetGWO/SADPEA）。RIS 算法（IMM/TIM/TIM+/OPIM/OPIM-C）为 C++ 模块，保持 `Set[int]` 返回类型不变。
